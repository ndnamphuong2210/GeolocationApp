NUMBER TOOLS APP
Click RUN the code to create an app for calculating n^2, n^3, n!, check the prime, calculate the gcd. 
The results are returned when the button in results box is clicked and the users can also remove all their input with "Delete" button. "Help" button assists the users to contact the person who codes the app. In addition, in calculating factorial number function, it only works for input number from 0 to 20 as numbers out of the range may crash the program.
